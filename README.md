# Sistemas Operacionais 2

## Descrição
Este repositório contém as soluções para os 10 exercícios da Lista 01 da disciplina de Sistemas Operacionais 2, implementados em Python.

## Exercícios Implementados

1. **Corrida de Cavalos** - Threads com largada sincronizada e aposta
2. **Buffer Circular** - Produtores e consumidores com semáforos
3. **Transferências Bancárias** - Simulação com e sem locks
4. **Pipeline** - Processamento em três estágios com filas limitadas
5. **Pool de Threads** - Processamento de tarefas CPU-bound
6. **Processamento Paralelo** - Soma e histograma com P threads
7. **Jantar dos Filósofos** - Duas soluções para deadlock
8. **Buffer com Bursts** - Backpressure e análise de estabilidade
9. **Corrida de Revezamento** - Barreiras e sincronização
10. **Watchdog** - Detecção de deadlock com ordem global

## Tecnologias Utilizadas
- Python 3.7+
- Threading
- Multiprocessing
- Queue
- Matplotlib (para gráficos)
